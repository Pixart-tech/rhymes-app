Testing School Creator

Uses POST /api/testing/schools and does not increment the production school counter. The backend must be started with ENABLE_TESTING_INTERFACE=true.

Login (Firebase)

This logs into the same Firebase project as the main app and fetches an ID token automatically. If you see an “unauthorized domain” error, add this site (e.g. localhost) to Firebase Auth → Settings → Authorized domains.
